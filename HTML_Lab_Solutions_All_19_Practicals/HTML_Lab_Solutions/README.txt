HTML LAB PRACTICAL SOLUTIONS
Based on: Lab Session 1 - Lab Setup & Environment Configuration

How to use:
1. Extract this ZIP file.
2. Open the HTML_Lab_Solutions folder in Visual Studio Code.
3. Open any practical file (01 to 19).
4. Right-click the file and choose "Open with Live Server", or open it directly in Google Chrome.
5. For Practical 17, open 17_college_website/index.html.
6. For Practical 18, open 18_ecommerce_catalogue.html.
7. For Practical 19, open 19_capstone_educational_institute/index.html.

All practicals use HTML. Some pages refer to local sample images/media; where needed, replace the sample file paths with your own files.
